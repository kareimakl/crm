# 🕌 نظام إدارة الحج والعمرة - CRM System

نظام شامل لإدارة خدمات الحج والعمرة مع نظام صلاحيات متقدم مبني على Firebase Auth و Firestore.

## ✨ المميزات

### 🔐 نظام المصادقة والصلاحيات
- **Firebase Authentication** مع البريد الإلكتروني وكلمة المرور
- **نظام أدوار متقدم** مع صلاحيات قابلة للتخصيص
- **حماية البيانات** عبر Firestore Security Rules
- **واجهة إدارة الأدوار** للمدير العام

### 📊 الأقسام المدعومة
- **الفروع** - إدارة فروع الشركة
- **المخازن** - إدارة المخازن والمستودعات
- **الرحلات** - إدارة رحلات الحج والعمرة مع قوائم الأعضاء
- **الموظفين** - إدارة شاملة للموظفين والرواتب والتقارير
- **الحجاج** - إدارة بيانات الحجاج والمعتمرين
- **التوريدات** - إدارة التوريدات والمخزون
- **التذاكر** - إدارة تذاكر الطيران والإقامة
- **الفواتير** - إدارة الفواتير والمدفوعات
- **سائقين الحافلات** - إدارة السائقين والحافلات
- **الفنادق** - إدارة الفنادق والشراكات
- **المنتجات** - إدارة المنتجات والخدمات
- **نظام الولاء** - إدارة برامج الولاء والعملاء
- **الموارد البشرية** - إدارة شؤون الموظفين
- **التقارير** - تقارير شاملة ومفصلة
- **الإعدادات** - إعدادات النظام والأدوار

### 🎯 الأدوار الافتراضية
1. **مدير عام (super_admin)** - صلاحيات كاملة على جميع الأقسام
2. **مدير فرع (branch_admin)** - إدارة فرع محدد مع صلاحيات محدودة
3. **مندوب (rep)** - إدارة الحجاج والتذاكر فقط
4. **محاسب (accountant)** - إدارة الفواتير والتقارير المالية

## 🚀 التثبيت والإعداد

### المتطلبات الأساسية
- Node.js (v14 أو أحدث)
- npm أو yarn
- حساب Firebase

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd mostashar-elmadina-crm
```

2. **تثبيت التبعيات**
```bash
npm install
```

3. **إعداد Firebase**
   - إنشاء مشروع Firebase جديد
   - تفعيل Authentication (Email/Password)
   - إنشاء Firestore Database
   - تفعيل Storage (لرفع الملفات)
   - نسخ بيانات التكوين من Firebase Console

4. **تحديث بيانات Firebase**
   - فتح `src/firebase/config.js`
   - تحديث `firebaseConfig` ببيانات مشروعك

5. **نشر قواعد Firestore**
```bash
firebase deploy --only firestore:rules
```

6. **تشغيل المشروع**
```bash
npm start
```

## 🔧 الإعدادات المتقدمة

### إضافة قسم جديد
1. إضافة اسم القسم في `src/constants/permissions.js`
2. إضافة الصفحة في `src/pages/`
3. إضافة المسار في `src/App.js`
4. تحديث قواعد Firestore في `firestore.rules`

### تخصيص الأدوار
1. الدخول كمدير عام
2. الانتقال إلى إدارة الأدوار
3. إنشاء دور جديد أو تعديل دور موجود
4. تحديد الصلاحيات لكل قسم

### إضافة مستخدم جديد
1. الدخول كمدير عام
2. إنشاء حساب Firebase Auth
3. إضافة بيانات المستخدم في Firestore
4. تعيين الدور المناسب
